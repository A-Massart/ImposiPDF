# ImposiPDF

ImposiPDF est un outil Python pour imposer les pages d’un PDF en format cahier avec traits de coupe.  
Il permet de transformer un PDF standard en un PDF prêt à être imprimé en livret.

---

## Contenu du dossier

Le dossier `ImposiPDF` contient :
- `ImposiPDF/` → code source
- `IMPOSIPDF__Mac/` → version macOS de l'application (contient .app)
- `IMPOSIPDF__Win/` → version Windows de l'application (contient .exe)
---

## Prérequis

Aucun 😎

## Étapes d’installation

1. Télécharger le dossier `ImposiPDF/`.  
2. À l'intérieur, récupérer l'application correspondante à votre système d'exploitation et la dupliquer dans vos applications pour macOS ou dans le dossier qui vous arrange pour Windows.
3. Double-cliquer pour ouvrir l'app.  
Autoriser l'ouverture de l'app outre le message d'avertissement (peut-être dans les paramètres pour certains systèmes).

#### 4. Attendre un peu !
L'app met du temps  s'ouvrir la première fois...
